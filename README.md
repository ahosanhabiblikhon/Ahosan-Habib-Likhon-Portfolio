# Ahosan Habib Likhon - Personal Portfolio Website V7

A modern, biotechnology-inspired personal portfolio website showcasing my journey as a Biotechnology & Genetic Engineering student, aspiring developer, researcher, and creative photographer.

## 🧬 Features

- **Biotechnology-Inspired Design**: Scientific theme with DNA, cells, and molecular elements
- **Scientific Background Animations**: Interactive DNA helix particles and molecular structures
- **Fully Responsive**: Optimized for all devices (desktop, tablet, mobile)
- **Dark/Light Mode**: Toggle between themes with smooth transitions
- **GitHub Integration**: Automatically fetches and displays public repositories
- **Photography Gallery**: Masonry-style gallery with category filters
- **Smooth Animations**: Custom cursor, scroll animations, and transitions
- **SEO Optimized**: Meta tags, Open Graph, Twitter Cards
- **Performance Optimized**: Fast loading, lazy loading images
- **Modern Tech Stack**: Pure HTML5, CSS3, and Vanilla JavaScript (ES6)

## 🚀 Quick Start

### Local Development

1. Clone or download this repository
2. Open `index.html` in your web browser
3. That's it! No build process required.

### GitHub Pages Deployment

1. Push this repository to GitHub
2. Go to Settings → Pages
3. Select the branch (usually `main`)
4. Your site will be live at `https://yourusername.github.io/repository-name`

## 🖼️ Customization

### Personal Information

Edit `index.html` to update:
- Name and title
- About section content
- Education details
- Skills and expertise
- Social media links
- Contact information

### Photography Gallery

1. Add your photos to `assets/images/photography/`
2. Update the gallery section in `index.html`
3. Set appropriate `data-category` attributes (nature, portrait, mobile)

### Color Theme

Modify CSS variables in `style.css`:
```css
:root {
  --accent: #10b981;  /* Primary green */
  --accent-2: #14b8a6; /* Teal */
  --accent-3: #06b6d4; /* Cyan */
  /* ... more variables */
}
```

### Resume/CV

Replace `assets/resume.pdf` with your actual resume file.
